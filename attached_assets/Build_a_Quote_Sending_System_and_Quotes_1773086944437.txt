Build a Quote Sending System and Quote View Tracking feature for a travel agency CRM.

This feature allows travel agents to send customers a unique quote link and track when the customer views the quote.

SYSTEM OVERVIEW

Each quote must generate a unique secure URL token.

Example:

https://app.platform.com/quote/7F3K2L

This URL opens the customer quote page.

Agents must be able to send this link directly from the Quote Details page inside the CRM.

QUOTE DATABASE STRUCTURE

Create a quotes table with the following fields:

quote_id
customer_id
quote_token
total_price
deposit_required
status
created_at
updated_at

quote_token must be a secure random string.

Example:

7F3K2L
A9X4P2
K83ZL1

QUOTE VIEW TRACKING TABLE

Create a table called:

quote_views

Fields:

view_id
quote_id
viewed_at
ip_address
device_type
browser
country (optional)

WHEN A CUSTOMER OPENS A QUOTE

When the quote page loads:

Identify the quote using the token in the URL.

Log a new record in the quote_views table.

Capture:

timestamp
IP address
device type (mobile/desktop/tablet)
browser

Example log entry:

quote_id: 1043
viewed_at: 2026-03-09 19:42
device_type: mobile
browser: Chrome

SHOW VIEW DATA TO AGENTS

Inside the CRM Quote Page show:

Quote Views

Example display:

Quote viewed 3 times
Last viewed today at 19:42
First viewed yesterday at 14:05

Optional advanced data:

Device breakdown
Mobile: 2

REAL-TIME VIEW ALERTS (OPTIONAL)

When a quote is opened, send a notification to the agent.

Example:

SECURITY

The quote must only be accessible via the unique token.

Example:

/quote/{token}

Do not expose quote IDs.

TECH REQUIREMENTS

Build this using:

REST API endpoints

GET /quote/{token}
POST /quote/send
POST /quote/view-log

Ensure the quote page is mobile friendly and loads quickly.

GOAL

Allow agents to easily send quotes and track customer engagement.

Agents should know:

• If the customer opened the quote
• How many times it was viewed
• When it was last viewed
